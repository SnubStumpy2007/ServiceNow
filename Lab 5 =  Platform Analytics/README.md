# ServiceNow Lab Report – Create an Incident Priority Pie Chart

## Lab Title

**Create an Incident Priority Pie Chart**

## Objective

The objective of this lab was to create a data visualization that displays the distribution of active incidents by Priority within ServiceNow. This visualization provides a quick overview of the incident workload and was saved for future use.

## Environment

* **Platform:** ServiceNow
* **Application:** Incident Management
* **Module:** Incident > All

## Procedure

1. Navigated to **Incident > All**.
2. Applied a filter so that only active incidents were displayed:

   * **State** | **is not** | **Closed**
3. Selected **Run** to apply the filter.
4. Right-clicked the **Priority** column header and selected **Pie Chart**.
5. Examined the pie chart by hovering over each slice to identify the percentage represented by each Priority level.
6. Opened the **Details** panel.
7. Renamed the chart to **Open Incidents by Priority**.
8. Saved the visualization.

## Results

A pie chart was successfully generated showing the percentage distribution of all open incidents grouped by Priority. Hovering over each section of the chart displayed the percentage of incidents for each priority level, making it easy to identify which priority contained the largest number of active incidents.

## Skills Demonstrated

* Filtering incident records
* Creating data visualizations
* Using ServiceNow reporting features
* Interpreting graphical data
* Saving reusable dashboard visualizations

## Outcome

The lab was completed successfully. A saved visualization named **Open Incidents by Priority** now provides a quick graphical summary of active incidents by Priority, allowing administrators and service desk personnel to identify workload trends more efficiently.
