# ServiceNow Lab: Access a Password Reset Knowledge Base Article

## Objective

Use the Service Portal and Virtual Agent to locate a password reset Knowledge Base article, mark it as helpful, provide a five-star rating, and submit feedback.

---

## Lab Environment

- **Platform:** ServiceNow
- **Module:** Service Portal
- **Feature:** Virtual Agent
- **Knowledge Article:** KB0010003

---

## Task Steps

### Step 1: Open the Service Portal

From your ServiceNow instance URL, append:

```text
/sp
```

Example:

```text
https://instance.service-now.com/sp
```

This opens the **Service Portal**.

---

### Step 2: Open Virtual Agent

1. Locate the **Open Chat Window** button in the lower-right corner of the screen.
2. Select it to launch **Virtual Agent**.

---

### Step 3: Search for Password Help

In the chat field labeled:

> **"Please type your request"**

Type:

```text
change password
```

Press **Enter**.

---

### Step 4: Select the Password Reset Option

Virtual Agent presents two options:

- **Password Reset Instructions**
- **I want something else**

Select:

**Password Reset Instructions**

---

### Step 5: Open the Knowledge Article

Virtual Agent recommends the following article:

**KB0010003**

Select **KB0010003** to open the Knowledge Base article.

---

### Step 6: Mark the Article as Helpful

At the bottom of the article:

1. Locate the **Helpful?** section.
2. Select **Yes**.

---

### Step 7: Rate the Article

Provide a rating of:

⭐⭐⭐⭐⭐ **5 Stars**

---

### Step 8: Submit Feedback

Enter any comment of your choice.

Example:

> *"Clear instructions and easy to follow."*

Select **Submit** to save your feedback.

---

## Expected Result

The password reset Knowledge Base article is opened, marked as helpful, rated with five stars, and feedback is successfully submitted.

---

## Validation Checklist

- ✅ Opened the Service Portal.
- ✅ Launched Virtual Agent.
- ✅ Searched for **"change password"**.
- ✅ Selected **Password Reset Instructions**.
