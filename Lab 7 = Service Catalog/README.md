# ServiceNow Lab: Order a Desktop Phone and Adobe Acrobat Pro

## Objective

Use the Service Catalog to order a desktop phone and Adobe Acrobat Pro, then submit the request through the checkout process.

---

## Lab Environment

- **Platform:** ServiceNow
- **Module:** Service Catalog
- **Categories:** Office, Software

---

## Task Steps

### Step 1: Open the Service Catalog

Navigate to:

**All → Self-Service → Service Catalog**

> **Tip:** If you are still in the Service Portal from a previous exercise, remove the `/sp` portion of the URL to return to the standard ServiceNow Platform view.

---

### Step 2: Order a Desktop Phone

1. Select the **Office** category.
2. Scroll through the available catalog items.
3. Select **Telephone Extension (IP 560 Phone)**.
4. Select **Add to Cart**.

---

### Step 3: Continue Shopping

After adding the phone:

1. Select **Continue Shopping**.

This returns you to the Service Catalog so additional items can be added before checkout.

---

### Step 4: Order Adobe Acrobat Pro

1. Return to the **Service Catalog** home page.
2. Select the **Software** category.
3. Select **Adobe Acrobat Pro**.
4. Select **Add to Cart**.

> **Expected Result:** Your shopping cart now contains **2 items**.

---

### Step 5: Checkout

1. Select **Proceed to Checkout**.
2. Review the items in your cart.
3. Submit the request.

---

## Expected Result

After submitting the order, the Service Catalog header should display:

> **"Thank you, your request has been submitted."**

This confirms that both catalog requests were successfully submitted.

---

## Validation

Verify the following:

- ✅ Telephone Extension (IP 560 Phone) was added to the cart.
- ✅ Adobe Acrobat Pro was added to the cart.
- ✅ Both items appeared in the shopping cart.
- ✅ The request was successfully submitted.
- ✅ The confirmation message was displayed.

## Key Takeaways

- The Service Catalog allows users to request hardware, software, and services from a centralized location.
- Multiple catalog items can be added to a single shopping cart before checkout.
- The checkout process consolidates requests into a single submission.
- The confirmation message **"Thank you, your request has been submitted."** indicates a successful Service Catalog request.
