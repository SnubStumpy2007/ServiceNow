# ServiceNow Hands-On Labs

A collection of hands-on ServiceNow labs completed to develop practical experience with the ServiceNow platform. This repository documents each exercise with step-by-step procedures, screenshots, and key concepts learned.

## Purpose

The goal of this repository is to demonstrate practical ServiceNow administration and platform skills while building experience commonly expected in IT Help Desk, Desktop Support, and Junior System Administrator roles.

Each lab is organized into its own folder and includes documentation that can be reproduced by another learner.

---

## Skills Demonstrated

* ServiceNow navigation
* User administration
* User impersonation
* Role-Based Access Control (RBAC)
* Knowledge Management
* Service Catalog
* Incident Management
* Interface customization
* Lists and forms
* Application navigation
* IT Service Management (ITSM) fundamentals
* Technical documentation
